# Archived package history

This branch keeps all historical vosfs and fss-cli commits reachable without
maintaining a separate branch for every former feature branch or GitHub PR head.
It contains no legacy Python vos package ancestry.

Use `main` for development. The original 25 release tags retain their exact
objects. `refs.json` maps each original source ref to its preserved commit or
tag object; those commits remain reachable through this archive commit's
parents. The migration record on main contains the same mapping and audit.

Do not rewrite or delete this archive branch: it retains work that was squashed
before reaching the original main branches.
